# 단어장 앱 (PWA)

노트북 / 안드로이드 폰 / 태블릿(펜)에서 쓰는 단어 암기 앱. **Google 스프레드시트**와 자동 동기화됩니다.

## 1. 지금 바로 써보기 (노트북, 동기화 없이)
이 폴더에서:
```
python -m http.server 8765
```
브라우저에서 http://localhost:8765 → 설정 → "불러오기"로 `단어_암기_리스트_v2.xlsx` 선택.

## 2. 인터넷에 올리고 폰/탭에 설치 (HTTPS 필요)
1. GitHub에 새 저장소(예: `wordapp`)를 만들고 **이 폴더의 내용을 저장소 루트에** 올립니다 (`.github` 폴더 포함, 기본 브랜치 `main`. 엑셀은 `.gitignore`로 자동 제외).
2. 저장소 Settings → Pages → Source: **GitHub Actions**.
3. Actions 탭 → "음성 생성 + 배포" → Run workflow. 끝나면 `https://<아이디>.github.io/wordapp/` 가 앱 주소입니다.
4. 폰/탭 Chrome에서 그 주소 → ⋮ 메뉴 → **앱 설치**.

## 3. Google 스프레드시트 연결 (1회)
**A. 시트 만들기**
1. drive.google.com → 새로 만들기 → 파일 업로드 → `단어_암기_리스트_v2.xlsx`
2. 업로드된 파일 우클릭 → 연결 앱 → Google 스프레드시트 → 열린 뒤 **파일 → Google 스프레드시트로 저장**.
3. 시트 탭 이름이 `단어`, 1행 머리글이 `ID, 날짜, 언어 …` 인지 확인. 주소창의 주소를 복사해 둡니다.

**B. Google Cloud에서 Client ID 받기** (무료, 카드 불필요)
1. https://console.cloud.google.com → 새 프로젝트 만들기
2. API 및 서비스 → 라이브러리 → **Google Sheets API** 사용 설정
3. API 및 서비스 → OAuth 동의 화면 → 외부 → 앱 이름(예: 단어장), 이메일 입력 → **테스트 사용자에 본인 Gmail 추가**
4. 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 유형 **웹 애플리케이션**
   - 승인된 JavaScript 원본: 앱 주소의 origin (예: `https://아이디.github.io`, 노트북 테스트용 `http://localhost:8765`)
5. 만들어진 **클라이언트 ID**(…apps.googleusercontent.com)를 복사

**C. 앱에서**
설정 → Google Client ID, 스프레드시트 주소 입력 → **Google 로그인** (처음엔 "확인되지 않은 앱" 경고 → 고급 → 계속).

※ 로그인은 1시간마다 만료됩니다. 앱은 자동으로 조용히 갱신하려 하고, 안 되면 설정의 "지금 동기화"를 한 번 누르면 됩니다.

## 4. 자동 음성 생성 (선택)
매일 04:00(KST)에 새 단어의 신경망 음성을 만들어 앱에 배포합니다.
1. Google 시트 → 공유 → 일반 액세스 **"링크가 있는 모든 사용자 — 뷰어"** (링크를 아는 사람은 단어장을 볼 수 있어요. 싫으면 이 단계를 건너뛰고 노트북에서 `python tools/gen_audio.py 단어_암기_리스트_v2.xlsx` 실행).
2. 저장소 Settings → Secrets and variables → Actions → New repository secret: 이름 `XLSX_URL`, 값 = 시트 주소.

## 5. 시트 자동 채우기 (선택, 추천)
단어만 적으면 ID·날짜·언어·기본값을 채우고, **뜻이 비어 있으면 구글 번역으로 채웁니다** (메모에 "자동번역" 표시). 앱에서 뜻 없이 추가한 단어도 5분 안에 채워집니다.
1. 구글 시트 → 확장 프로그램 → Apps Script
2. `tools/sheet_autofill.gs` 내용을 전부 붙여넣고 저장
3. 위쪽 함수 선택에서 **setup** → ▶ 실행 → 권한 허용 (경고가 나오면 고급 → 이동 → 허용)
4. 시트의 파일 → 설정에서 시간대를 **서울**로 맞춥니다.
※ 자동번역은 한 가지 뜻만 줍니다. 메모가 "자동번역"인 단어는 한 번 확인하세요. 스페인어는 `언어` 칸에 "스페인어"를 한 번 적어 두면(같은 출처는 자동 추정) 맞게 번역합니다.

## 동기화 방식
- 같은 ID는 "한쪽만 바뀌었으면 그쪽, 양쪽이면 수정일시가 최신인 쪽"을 채택합니다.
- 시트에서 ID를 비워 새 단어를 추가하면 앱이 ID를 부여해 되돌려 씁니다.
- 앱에서 삭제는 `삭제=TRUE`(숨김 처리)입니다.
- 시트의 열 순서(A~P)와 `단어` 시트 이름을 바꾸지 마세요.

## 기능
- 🃏 학습: 암기 / 리콜 / 스펠 / 매칭 / 크래시 / 테스트 / ✍️ 필기(펜 압력, 지우개 버튼, 손바닥 무시, 따라쓰기)
- 🎧 듣기: 걸으면서 단어→뜻 자동 낭독 (신경망 음성)
- 📚 단어: 검색/필터/추가/수정/일괄 붙여넣기
- 📊 통계: 암기율, 오늘 복습, 자주 틀리는 단어
